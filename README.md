# Number Guessing Game

A terminal game written in Python. The computer picks a random number
between 1 and 100, and the player has 5 chances to guess it.

## How to run

1. Install Python 3.
2. Run: python number_guessing_game.py
3. Type a number between 1 and 100 when asked.

The game ends when you guess correctly or use all 5 chances.
